🗺️ How a prediction is made

1

Enter features

Type in (or pick a preset for) duration, packet count, bytes and failed connections.

2

Scale the numbers

Values are log-scaled and standardised so big numbers don't overpower small ones.

3

Find {{ metrics.best_k }} neighbours

The model finds the {{ metrics.best_k }} most similar records in the training data.

4

Vote & log

Majority vote gives Normal or Suspicious, plus a confidence. The result is stored.

🔢 The 4 features

  • ⏱️ Connection durationHow long it lasted. Floods are often very short.
  • 📦 Packet countHow many packets were sent. Huge counts can mean flooding.
  • 💾 Bytes transferredTotal data volume sent.
  • ❌ Failed connectionsFailed attempts. Many failures suggest scanning or password guessing.

⚠️ Important limitations
  • The dataset is synthetic sample data ({{ metrics.normal_rows + metrics.suspicious_rows }} rows), so the accuracy shown is a learning demo, not a claim about real-world protection.
  • The model predicts from traffic features only. An IP address alone is never proof of malicious activity.
  • It does not monitor live network traffic or capture packets. You enter values or use the presets.
  • A "suspicious" result is a prompt to investigate, not a final verdict.
